# Checkpoint record, 2026-10-09: superseded data, its problems, and the decisions

Every dataset below is **kept** in `experiments/cluster-records/` and committed.
None is deleted. Each was superseded for a stated reason, and that reason led
to a stated decision. This file is the index; the full reasoning is in
`FINAL-PLAN-2026-10.md` sections 12.13 to 12.14e. Tag
`archive-2026-10-09-pre-amendment` holds the repository as it stood before
the day's changes.

**How to read it.** A checkpoint is real measured data, gathered under a design
that a later finding showed to be flawed. It stays as evidence of that
finding, and as pilot data. It is **never** a confirmatory result.

## Update, later on 2026-10-09: approach A passed

The open-loop curves (`olc-12325349`, `olc-12325350`) and calibration v3
(`stage2-12325359/62/65`, `stage2het-12325360/63/66`) finished. Rule v3
chose **h = 0**: every policy, cell and seed met the SLO for 100% of
requests, with no fallback. Plan 12.14d records two findings to settle
before the amendment is frozen. The H1 baseline `slo_packing` fills the
A100s first only because they are listed first. And calibration did not
reach the loads where the mixed fleet needs its RTX 6000s.

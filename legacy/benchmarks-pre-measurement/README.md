# benchmarks/ from the first design: synthetic data and an unrun plan

This folder was `benchmarks/` at the repository root until 2026-10-09. It was
moved here unchanged with `git mv`; the previous layout is kept by the tag
`archive-2026-10-09-pre-amendment`.

**Nothing here is a measurement.** It holds:

| Path | What it is |
|---|---|
| `scripts/generate_realistic_telemetry.py` | Writes **synthetic** telemetry, by its own docstring "Production-Grade Synthetic Telemetry" with imperfections added "to make the data credible". Its output directory was named `results/frontenac/`, which made it look measured |
| `scripts/generate_figures*.py` | Draw `docs/figures/fig1` to `fig16` from that synthetic data |
| `scripts/generate_*diagrams*.py`, `generate_dvfs_plot.py`, `generate_edp_plot.py` | Draw the data-style plots in `docs/diagrams/` from values written into the code, or drawn at random |
| `scripts/frontenac/` | The June 2026 "simulation-validated" plan for Frontenac. Never used for any result; several of its stated facts were later shown wrong (see its README) |
| `scripts/run-*`, `setup-benchmark-cluster.sh`, `analyze_results.py` | The first design's benchmark harness for a Kubernetes cluster with power capping, neither of which this project had |
| `profiles/`, `traces/` | Hand-written hardware profiles (H100, L4, ...) and sample workload traces |

The scripts' paths are hard-coded to `benchmarks/`, so they no longer run from
the repository root unchanged. That is deliberate: nothing in the current
project should call them.

Measured data is in `experiments/cluster-records/`. Measured figures are in
`docs/figures/measured/`, regenerated by `experiments/scripts/make_figures.py`.
